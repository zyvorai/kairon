  • OVA / VMDK import, OCI disk images
MOVE

Migration that refuses to guess

  • Cold, evacuation and mTLS live migration

  • NeedsRecovery: no silent split-brain
  • Disruption budgets and policies

Data and network

  • Snapshots and backups with guest freeze
  • CSI, block PVCs, Ceph RBD via Atlas
  • eBPF edge: DNS / SNI policy, rate limits
  • Flows, attributed drops, one-VM pcap
AUTOMATE

Built for agents and GitOps

  • MCP server: sandboxes, forks, egress
  • Kubernetes API is the only truth
  • Helm OCI or kaironctl install
  • Dashboard with SSO and VNC console
